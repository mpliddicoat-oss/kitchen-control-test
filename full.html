📚 Full User Guide

Complete documentation for every feature in Kitchen Control.

🚚 Suppliers

Suppliers are the foundation of your ingredient costing and ordering system.

Adding a Supplier

  1. Go to Suppliers → Add Supplier
  2. Enter supplier name, contact details, account number and delivery days
  3. Set an order cut-off time if applicable
  4. Save the supplier

Multiple Suppliers per Ingredient

Ingredients can be linked to multiple suppliers. Kitchen Control automatically uses the cheapest cost per unit when calculating recipe costs.

🥂 Ingredients

Ingredients are the core of the Kitchen Control system. Every recipe, dish and allergen flows from accurate ingredient data.

Pack Size & Costing

Enter the pack size and pack cost to get an accurate cost per unit. If you buy by the case, enter the case size and case cost and Kitchen Control calculates the pack cost automatically.

Allergen Scanning

Click Scan Ingredients Label to photograph the product packaging. Kitchen Control reads the ingredients list and automatically detects all 14 major allergens.

Invoice Scanning

Scan supplier invoices to automatically update ingredient prices. Go to Dashboard → Import Invoice.

⚖ Yields

Yields calculate the true cost of a prepared ingredient by accounting for trim loss, cooking loss or portioning.

Examples

  • Whole salmon → filleted portions
  • Chicken → trimmed breast
  • Vegetables → prepped and trimmed
  • Stock reductions

A yield takes a base ingredient and calculates the true cost per usable unit — giving significantly more accurate GP calculations.

📖 Recipes

Recipes combine ingredients, yields and other recipes into fully costed preparations.

Components

Add ingredients, yields or sub-recipes as components. Enter quantities and units. Kitchen Control calculates the total cost and cost per yield unit automatically.

Yield Units

Set the recipe yield quantity and unit (portions, grams, litres etc.) so cost per unit displays correctly throughout the system.

🍽 Dishes

Dishes combine recipes into customer-facing menu items with live GP% tracking.

GP% Calculation

Enter your sell price (inc. VAT) and Kitchen Control calculates gross profit percentage automatically. A target GP% is shown for reference.

Allergen Cascade

Allergens flow automatically from ingredients → recipes → dishes. No manual allergen entry needed at dish level.

📋 Menus

Menus organise dishes for service. Dishes can be manually ordered using the ▲▼ arrows.

Course Ordering

Dishes automatically group by category — Starters, Mains, Sides, Desserts, Children's Menu etc. Use the arrow buttons to fine-tune the order within each course.

⚠ Allergen Sheet

The allergen sheet generates a Natasha's Law compliant allergen matrix automatically from your ingredient data.

Views

  • By Dish — allergen matrix for a specific dish showing all components
  • By Recipe — allergen breakdown for a specific recipe
  • By Ingredient — full allergen matrix for all ingredients
  • By Menu — complete menu allergen matrix for printing

Manual Allergens

Click any grey dot to manually add an allergen. Click an orange ringed dot to remove a manually added allergen. Auto-detected allergens cannot be removed.

Important: Always verify allergen information independently before serving customers.

📦 Ordering

Generate ingredient order lists from your menus based on expected covers.

  1. Select a menu
  2. Enter expected covers or portions
  3. Generate order list
  4. Ingredients are grouped by supplier automatically
  5. Print or export your order sheet
